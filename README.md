# MOG BATTLE — @MOGGEDSTARSBOT

Telegram-бот, который сравнивает профили двух игроков и объявляет победителя. Результат приходит картинкой-карточкой.

## Как это работает

1. Игрок бросает вызов: inline `@MOGGEDSTARSBOT mogg` в любом чате, «Батл в личке» по `@username`/ID или «Реванш» под результатом.
2. Для каждого считаются 7 оценок от 0 до 10:

| Параметр | Откуда данные |
|---|---|
| Аватар | число фото профиля |
| @username | длина, буквы, цифры и `_` в нике |
| О себе | наличие и длина био |
| Premium | статус из апдейтов игрока |
| Оформление | 0–4: эмодзи-статус, цвет профиля, день рождения, бизнес-профиль |
| Дата рег. | оценка по возрасту `user_id` |
| Опыт в боте | батлы и победы игрока в этом боте |

3. Оценки усредняются с весами (ник, Premium и возраст аккаунта весят больше), к ним добавляется случайный сдвиг «форма дня».
4. Если разница меньше 0,15 — **ничья**. Иначе побеждает тот, у кого счёт выше.
5. Победы, поражения и ничьи пишутся в SQLite. Ранги по числу побед: Sub 3, Sub 5, Ltn, Mtn, Htn, Chad, True Adam.

На карточке результата видно счёт по раундам (сколько параметров выиграл каждый), параметр, который решил исход, перевес у победителя и веса параметров. Если победил заметно более слабый профиль, это отмечается как **апсет**. «Форма дня» каждого игрока показывается в подписи, кнопка «Как считается» и команда `/how` объясняют формулу. Кнопка «Поделиться результатом» подставляет счёт в текст для пересылки.

Реванш доступен один раз на батл и только его участникам.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | меню (и приём реферальной ссылки `?start=ref_ID`) |
| `/me` | ранг, победы/поражения/ничьи, винрейт, серия, место в топе, приглашённые |
| `/topmog` | топ-10 по победам (inline: `@MOGGEDSTARSBOT top`) |
| `/week` | топ недели: победы с понедельника (inline: `week`) |
| `/history` | последние 5 батлов |
| `/duel` | батл с игроком: ответом на его сообщение (работает в группах) или `/duel @username` |
| `/spar` | тренировка с ботом-соперником, в рейтинг не идёт |
| `/invite` | личная реферальная ссылка; за каждого друга «Опыт в боте» +0.3 (максимум +2) |
| `/hide` | скрыть себя из топов и вернуться обратно |
| `/stats` | статистика бота (только админ) |
| `/broadcast текст` | рассылка всем игрокам (только админ) |
| `/ban ID`, `/unban ID` | блокировка игрока (только админ) |

Дополнительно: повышение ранга и серия побед (3+) выводятся в подписи к результату; не более 6 батлов одной пары за час (против накрутки топа).

## Про Premium

Bot API отдаёт `is_premium` только в апдейтах самого пользователя, поэтому бот запоминает статус тех, кто ему писал или нажимал кнопки. Для незнакомого игрока на карточке будет «неизвестно», а оценка нейтральная.

## Запуск

Нужен Docker с Compose.

```bash
cp .env.example .env   # вписать BOT_TOKEN
docker compose up -d --build
docker compose logs -f bot
```

Переменные `.env`:

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather (inline-режим должен быть включён) |
| `CACHE_CHAT_ID` | чат, куда бот заливает карточки, если игрок не писал боту |
| `ADMIN_IDS` | id админов через запятую |
| `SUPPORT_URL` | ссылка кнопки «Поддержать» |

Без Docker: `pip install -r requirements.txt && python bot.py` (Python 3.10+).

## Деплой на VPS

```bash
bash deploy.sh
```

Скрипт заливает только код и пересобирает контейнер. `.env` и `ghostclash.db` на сервере не трогает. Ключ и хост задаются через `VPS_KEY` и `VPS_HOST`.

## Данные и бэкапы

- База `ghostclash.db` (SQLite) монтируется в контейнер как файл.
- Раз в сутки и при каждом запуске бот делает копию в `backups/`, хранятся последние 14.
- Открытые вызовы лежат в БД и живут 7 дней, поэтому переживают перезапуск.

## Структура

```
bot.py              хэндлеры, inline, батл, реванш, админка, бэкапы
stats.py            оценки, веса, ранги, случайность и ничья
database.py         SQLite: игроки, вызовы, батлы, kv
image_generator.py  карточки вызова, результата и фирменная заглушка
deploy.sh           выкладка на VPS
```
